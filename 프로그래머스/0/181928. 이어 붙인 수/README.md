## 💡 학습 노트: 이어 붙인 수 (String-based Accumulation)

### 1. 문제 핵심 요약
- **핵심 키워드**: `#forEach`, `#Type_Coercion`, `#String_Concatenation`
- **문제의 본질**: 배열의 요소를 특정 조건(홀/짝)에 따라 분류하고, 문자열로 결합한 뒤 최종 산술 연산을 위해 정수형으로 재변환하기.

### 2. 작동 원리 및 설계
1. **분류 바구니 생성**: 결합 연산을 위해 초기값을 빈 문자열(`""`)로 설정한 `odd_number`, `even_number` 변수 선언.
2. **배열 순회**: `forEach`를 활용하여 모든 원소를 검사.
3. **조건부 결합**: `number % 2` 결과에 따라 해당 문자열 변수에 원소 추가.
4. **최종 합산**: `Number()` 내장 함수를 통해 문자열을 숫자로 캐스팅 후 덧셈 수행.

### 3. 주요 기술 포인트
- **암시적 형변환 (Implicit Coercion)**: 문자열 변수에 `+=` 연산자로 숫자를 더할 때 발생하는 자동 타입 변환 활용.
- **고차 함수 활용**: 루프 제어 변수 없이 데이터에만 집중하는 `forEach` 순회 방식 적용.

### 4. 깨달은 점
- **데이터 타입의 유연성**: 자바스크립트에서 동일한 `+` 연산자가 데이터 타입에 따라 '합산'과 '결합'이라는 전혀 다른 결과를 낸다는 점을 명확히 이해함.
- **비즈니스 로직의 확장**: 이 패턴을 응용하면 특정 조건의 데이터를 문자열 로그로 남기거나, 복합적인 ID 값을 생성하는 로직에 활용 가능함을 인지함.
