## 💡 학습 노트: 특수 문자 출력하기

### 1. 문제 핵심 요약
- **핵심 키워드**: `#Escape_Character`, `#Console_Output`
- **문제의 본질**: 프로그래밍 언어에서 특수한 기능을 가진 문자를 '순수 문자'로 출력하는 방법 이해하기.

### 2. 작동 원리 및 설계
- **이스케이프(Escape) 원리**:
  - 자바스크립트에서 `\`(백슬래시)는 특정 문자와 결합하여 특수 동작을 수행함 (예: `\n`은 줄바꿈).
  - 이를 방지하고 문자 그대로 출력하려면 기능성 문자 앞에 `\`를 추가하여 기능을 무효화함.
- **주요 대상**: 
  - `\` → `\\`로 작성해야 문자 하나가 출력됨.
  - `'`, `"` → 문자열 구분자와 충돌을 피하기 위해 `\'`, `\"`로 작성.

### 3. 시행착오 및 깨달은 점
- **도구 선택의 유연성**: 모든 문제에 `fs`나 `readline`이 필요한 것은 아니며, 문제의 '입력' 유무를 먼저 파악하는 것이 효율적인 설계의 시작임을 깨달음.
- **문자열의 특수성**: 백엔드에서 JSON 데이터나 로그를 다룰 때 이스케이프 처리가 제대로 되지 않으면 데이터가 깨질 수 있다는 원리를 시각적으로 확인하는 계기가 됨.
