## 💡 학습 노트: 원소들의 곱과 합 (Accumulation Logic)

### 1. 문제 핵심 요약
- **핵심 키워드**: `#forEach`, `#Product_vs_Sum_Square`, `#Initial_Values`
- **문제의 본질**: 배열의 전수 조사를 통해 곱($\prod$)과 합($\sum$)의 제곱을 산출하고 대소 관계 비교하기.

### 2. 작동 원리 및 설계
1. **변수 초기화 (중요)**: 
   - 덧셈 누적기(`sum`): `0`으로 초기화.
   - 곱셈 누적기(`product`): `1`로 초기화.
2. **배열 순회**: `forEach` 콜백 함수 내에서 복합 대입 연산자(`+=`, `*=`)를 사용하여 실시간 누적.
3. **조건부 반환**: 삼항 연산자를 활용하여 $product < (sum)^2$ 관계 확인.

### 3. 주요 기술 포인트
- **연산의 항등원**: 곱셈 연산 시 초기값을 `0`으로 설정할 경우 발생하는 로직 오류를 방지함.
- **거듭제곱 표현**: `sum * sum` 보다 가독성이 좋은 `sum ** 2` 연산자 활용.

### 4. 시행착오 및 깨달은 점
- **forEach의 한계와 활용**: `forEach`는 중간에 멈출 수 없으므로(No break), 배열 전체를 끝까지 계산해야 하는 이번 문제와 같은 상황에 최적임을 배움.
- **디버깅 포인트**: 테스트 실패 시 연산 결과의 초기값과 부등호의 방향을 가장 먼저 체크하는 습관을 기름.
