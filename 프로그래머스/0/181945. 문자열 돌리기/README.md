## 💡 학습 노트: 문자열 돌리기 (for...of 활용)

### 1. 문제 핵심 요약
- **핵심 키워드**: `#Iteration`, `#for...of`, `#String_Iterable`, `#Clean_Code`
- **문제의 본질**: 입력된 문자열의 각 요소를 순차적으로 탐색(Traverse)하고, 표준 출력의 자동 개행 기능을 활용하여 세로로 출력하기.

### 2. 작동 원리 및 설계
- **이터러블(Iterable) 활용**: 자바스크립트의 문자열은 이터러블 객체이므로, `split('')`을 통해 배열로 변환하는 중간 과정 없이 `for...of` 문으로 즉시 순회가 가능함.
- **순회 흐름**:
  1. `input` 문자열에서 첫 번째 문자부터 마지막 문자까지 하나씩 `char` 변수에 할당.
  2. `console.log(char)`를 실행하여 문자를 출력하고 자동으로 줄바꿈(Line Feed) 수행.

### 3. 기술적 강점
- **메모리 효율성**: `split('')`을 사용하면 문자열과 동일한 크기의 새로운 배열 객체를 메모리에 추가로 생성해야 함. 하지만 `for...of`를 직접 문자열에 사용하면 추가 배열 생성 비용을 아낄 수 있어 성능 면에서 더 유리함 (O(n)).
- **가독성 및 유지보수**: 인덱스 변수(`i`) 관리나 부등호(` < `, ` > `) 조건식을 신경 쓸 필요가 없어 '휴먼 에러'를 원천 차단하는 간결한 코드를 작성할 수 있음.

### 4. 시행착오 및 깨달은 점
- **조건식의 함정**: 초기 `for`문 설계 시 발생했던 부등호 방향 오류(`i > length`)를 통해, 루프의 진입 조건과 종료 조건을 명확히 설정하는 것이 로직의 기초임을 재확인함.
- **최적의 도구 선택**: 인덱스(`i`)가 반드시 필요한 상황(예: 특정 위치 점프, 역순 순회 등)이 아니라면, 단순 순회에는 `for...of`가 가장 적합한 도구임을 깨달음.
